# 스트리트 타입 파이트 — 게임 디자인 문서 (GDD v0.1)

> 작업 제목. 2026-10-14 작성. 수치의 단일 출처는 [`src/config.ts`](../src/config.ts)와 [`src/sim/skills.ts`](../src/sim/skills.ts)이며, 이 문서 §13 표는 그 값을 옮겨 적은 것이다.

## 0. 한 줄 요약

**쿼터뷰 오픈월드에서 지나가던 상대를 지정하고, 자판으로 치고받는 실시간 타자 난투.**
키를 한 번 맞게 칠 때마다 주먹이 한 대 나가고, 스킬은 주문 단어로 쓰고, 날아오는 공격은 방어 단어를 쳐서 막는다. 타자 속도가 곧 공격 속도다.

## 1. 레퍼런스와 가져올 것

| 레퍼런스 | 가져오는 것 | 가져오지 않는 것 |
|---|---|---|
| 대난투 스매시브라더스 | 여럿이 뒤엉키는 난전, 날려 보내는 KO 연출, 짧은 판 | 플랫폼 액션 조작 |
| 테트리스 99 / 슈퍼 마리오 35 | **공격 대상 전략**(가까운 적 / 나를 노리는 적 / 빈사 적)과 자동 재지정 | 배틀로얄 탈락 구조 |
| 바람의 나라 | 방향키 이동 + 쿼터뷰 필드, 길에서 마주치는 PvP, 마을 = 안전지대 | 클릭 사냥, 장시간 성장 |
| 메이플스토리 | 2등신 캐릭터, 채널 개념 | 사이드뷰 |
| 라그나로크 / 페이퍼 마리오 | 3D 맵 위 2D 캐릭터(2.5D), 종이 오림 질감 | 외부 스프라이트 |
| 타이핑 오브 더 데드, 한컴타자 산성비 | 적 = 단어, 첫 글자 잠금 | 정해진 레일 진행 |

## 2. 디자인 기둥

1. **키 한 번 = 주먹 한 방** — 맞게 친 자모 하나하나가 즉시 화면·소리·피해로 돌아온다. 단어를 다 치기를 기다리지 않는다.
2. **속도가 생명, 정확도가 무기** — 타속은 공격 속도, 오타는 콤보 끊김이다. 빠르기만 하면 손해를 본다.
3. **길에서 붙는다** — 던전에 들어가지 않는다. 필드에서 보이는 사람을 지정하면 바로 싸움이 된다. 마을만 안전하다.
4. **읽고, 막고, 되받아친다** — 상대가 치는 스킬 단어가 머리 위에 보인다. 방어 단어로 막고, 빨리 막으면 되받아친다.
5. **입력은 막지 않는다** — 맞거나 넘어져도 타자 입력은 계속 받는다(KO 제외). 손이 멈추는 순간 재미가 끊기기 때문이다.

## 3. 핵심 루프

- **초 단위**: 대상 지정 → 공격 단어 연타(잽) → 마무리 강타 → 날아오는 공격 읽기 → 방어 단어 → 스킬 → 기세가 차면 필살기
- **분 단위**: 필드 이동 → 난전 합류 → KO / 다운 → 마을 부활 → 다시 출격. 한 판은 15킬 선승(봇 4:4 기준 약 2~2.5분)
- **장기(온라인 이후)**: 직업·주문서(스킬 단어) 수집, 칭호, 타속 리그, 세력전

## 4. 조작

| 입력 | 동작 |
|---|---|
| 글자키(두벌식) | 타자. 공격·스킬·방어·필살 단어를 친다 |
| Space | 속담(필살기)의 띄어쓰기 |
| ←↑↓→ | 이동(바람의 나라식). 글자키와 겹치지 않는다 |
| Tab | 교전 거리 안의 다음 적으로 대상 변경(직접 지정) |
| 1 · 2 · 3 | 대상 전략: 가까운 적 / 나를 노리는 적 / 빈사 상태 적 |
| Backspace | 지금 잠근 단어 취소 |
| Esc | 메뉴(계속하기 · 소리 · 처음 화면) |

**자동 전진**: 공격·필살 단어를 치는 동안 방향키를 누르지 않으면 대상에게 천천히 밀고 들어간다. 손을 방향키로 옮기지 않아도 난전이 형성되도록 한 장치다.

## 5. 타자 전투 시스템

### 5.1 입력 모델 — 키 토큰과 자체 두벌식 조합

- OS의 IME를 쓰지 않는다. `KeyboardEvent.code`(물리 키 위치) + Shift만 보고 두벌식 자모로 바꾼다. 그래서 **한/영 상태와 무관하게** 같은 판정이 나고, 조합 중 이벤트의 브라우저별 차이도 없다.
- 단어는 "키 토큰" 열로 분해해 판정한다. 예: `과` = ㄱ ㅗ ㅏ, `닭` = ㄷ ㅏ ㄹ ㄱ, `쌀` = ㅆ(Shift+T) ㅏ ㄹ.
- 화면에는 자체 오토마타로 조합한 모양을 보여 준다(친 글자 / 조합 중인 글자 / 남은 글자).
- 키 단위 판정이라 서버가 같은 입력을 그대로 재생해 검증할 수 있다(§11).

### 5.2 후보 단어와 첫 키 잠금

- 한 사람에게 동시에 떠 있는 단어(공격 1, 스킬 4, 방어 n, 필살 0~1)는 **첫 키가 모두 다르다**. 새 단어는 이미 쓰인 첫 키를 피해서 뽑는다.
- 첫 키로 어떤 단어를 칠지 잠기고, 이후는 다음 키만 맞으면 된다. 쿨타임·사거리 밖 스킬의 첫 키는 "준비 안 됨" 안내만 하고 벌칙은 없다.
- **방어 끼어들기**: 다른 단어를 치는 중이라도 방어 단어의 첫 키를 치면 곧바로 방어로 갈아탄다(잠금 해제 키를 따로 누르지 않는다).

### 5.3 공격 — 잽과 마무리 강타

- 내 대상 머리 위에 공격 단어(2~3음절, 5~8타)가 뜬다.
- 맞게 친 키 하나 = 잽 1회(피해 1.0 × 콤보 배율 × 근접 보너스). 대상이 2.6 이내면 근접 보너스 ×1.5.
- 마지막 키 = 마무리 강타(4 + 0.6 × 단어 타수, 넉백). 새 단어가 뜬다.
- 교전 거리는 8. 그 밖의 적은 대상이 될 수 없다.

### 5.4 스킬 — 시전 지연 동안 날아오는 방어 단어

- 스킬 단어를 다 치면 즉시 발동하지 않고 **시전 지연(착탄까지의 시간)**이 생긴다. 이 시간 동안 맞는 사람 머리 위와 HUD에 **방어 단어**와 줄어드는 시간 막대가 뜬다.
- 방어 단어 길이(타수)는 시전 지연 안에 보통 타자수(약 300타)가 반응 시간을 포함해 칠 수 있게 정했다(§13).
- 시전하는 사람의 머리 위에는 치고 있는 스킬 단어가 보인다. 상대는 그걸 읽고 대비할 수 있다.

### 5.5 방어와 반격

| 결과 | 조건 | 효과 |
|---|---|---|
| 반격(패리) | 남은 시간 40% 이상에서 방어 단어 완성 | 피해 0, 공격자에게 피해의 60% 반사, 공격자의 입력 잠금·콤보 해제, 기세 +12 |
| 방어 | 착탄 전에 완성 | 피해 0, 기세 +6 |
| 회피 | (범위기만) 착탄 순간 반경 × 1.25 밖 | 피해 0 |
| 피격 | 그 밖 | 피해, 넉백, 콤보 끊김 |

"빨리 막을수록 이득"이 핵심이다. 반격은 대략 360타 이상이면 노려 볼 수 있고, 보통 실력이면 방어에 그친다.

### 5.6 헛손질(오타)

- 틀린 키: 콤보 0, 기세 −6, 비틀거리는 연출. 잠금과 진행도는 유지된다.
- 첫 오타 뒤 0.4초 안의 연속 오타는 추가 벌칙 없이 무시한다. 빠르게 치다 보면 오타를 알아채기 전에 2~3타가 더 나가기 때문이다.
- 오타는 정확도 통계에 모두 들어간다.

### 5.7 콤보 · 기세 · 필살기

- **콤보**: 맞게 친 키마다 +1. 잽·강타 피해 배율 = 1 + min(콤보, 40)/40 × 0.5(최대 ×1.5). 오타나 스킬 피격 시 0.
- **기세**: 맞는 키 +0.6, 강타 +4, 방어 +6, 반격 +12, 오타 −6. 100이 되면 고정되고 필살기가 열린다. KO되면 0.
- **필살기**: 속담 한 줄(12음절 이하, Space 포함)을 친다. 사거리 10, 시전 지연 2.2초, 피해 45 + 띄우기, 주변 3 이내 다른 적에게 15. 맞는 쪽은 6~8타짜리 방어 단어로 막을 수 있다.

### 5.8 대상 지정

- 대상이 없거나 무효(사망·교전 거리 ×1.25 밖·안전지대)가 되면 **전략**대로 자동 재지정한다.
  - 1 가까운 적 · 2 나를 노리는 적(없으면 가까운 적) · 3 빈사 상태 적(체력 비율 최저)
- Tab은 교전 거리 안의 적을 가까운 순으로 돌아가며 직접 지정한다.
- 진짜 적이 있으면 허수아비보다 우선한다.

## 6. 캐릭터와 직업

### 6.1 프로토타입 키트 — 권사

| 스킬 | 첫 키 | 형태 | 요약 |
|---|---|---|---|
| 장풍 | ㅈ | 원거리 투사체 | 기를 모아 쏘는 원거리 일격 |
| 돌려차기 | ㄷ | 돌진 | 대상에게 돌진해 꽂는 회전 발차기, 넉백 큼 |
| 철벽 | ㅊ | 자기 강화 | 3초간 잽 무효, 스킬 피해 절반 |
| 회오리바람 | ㅎ | 범위 | 주변 모든 적, 착탄 전에 벗어나면 회피 |

### 6.2 이후 직업 구상(미구현)

- **술사**: 긴 주문 = 강한 원거리. 근접에 약하다. 주문서(스킬 단어 묶음)를 바꿔 끼운다.
- **도사**: 아군 회복·보호 단어. 아군의 방어 단어를 대신 쳐 주는 "대신 막기".
- **자객**: 짧은 단어, 낮은 피해, 은신(이름표 숨김), 뒤에서 치면 치명타.

직업마다 스킬 단어의 첫 키가 겹치지 않아야 하며, 첫 키 19종 중 스킬이 4개를 쓰고 나머지를 공격·방어·필살 단어가 나눠 쓴다.

## 7. 월드

- **맵**(80 × 52): 서쪽 청룡 마을, 동쪽 주작 마을, 가운데 태극 돌광장, 남북으로 흐르는 개울 두 줄과 다리 네 개(다리가 길목이 되어 난전이 잘 난다), 외곽 숲, 청룡 마을 옆 수련장(허수아비).
- **마을 = 안전지대**: 공격할 수도 맞을 수도 없고 체력이 초당 18 회복된다. KO되면 3초 뒤 자기 마을에서 부활한다.
- **허수아비**: 언제든 쳐 볼 수 있는 연습 상대. 3초간 안 맞으면 체력이 차오른다.

## 8. 프로토타입 매치 규칙

- 청룡단 4(나 + 봇 3) 대 주작단 4(봇), 15킬 선승. 허수아비 KO는 점수에 들어가지 않는다.
- 봇은 "가상의 타자수"다: 타속(초당 키)·정확도·반응 시간·방어 확률이 있고 플레이어와 똑같은 입력 경로로 한 키씩 친다. 난이도는 상대 봇의 타속 분포로 정한다(초보 약 180~270타, 보통 약 230~340타, 고수 약 300~400타).
- 결과 화면: 전투 타속(1.5초 넘게 쉰 구간 제외), 정확도, 최대 콤보, KO·다운·방어·반격, 입힌 피해.
- **점수 카드**(v0.2): 결과를 4:5 이미지로 저장·복사·공유한다. 마지막 장면 스냅샷, 승패, 전투 타속과 칭호(100타 단위 6단계: 동네 새내기 · 골목 주먹 · 장터 싸움꾼 · 마을 대장 · 고을 영웅 · 전설의 타자왕), 세부 기록, 게임 주소. 공유가 곧 홍보 경로이므로 "너는 몇 타로 싸워?" 문구로 도전을 유도한다.

## 9. 아트 디렉션

- **2.5D**: 3D 로우폴리 맵 + 카메라를 향해 눕힌 2D 종이인형 캐릭터. 카메라 방향은 고정(쿼터뷰, 약 47° 내려다봄)이라 캐릭터는 항상 정면이고, 좌우는 종이를 뒤집듯 반전한다.
- **외부 애셋 0**: 캐릭터 부위(머리·몸통·팔·다리), 표정 4종, 기와집 벽, 장승 얼굴, 깃발, 물결, 이펙트 스프라이트를 모두 캔버스에 코드로 그린다. 폰트도 시스템 한글 폰트만 쓴다.
- **종이 오림 질감**: 부위마다 흰 여백 테두리 + 잉크 외곽선. 캐릭터는 조명을 받지 않아(unlit) 배경 위에서 또렷하게 뜬다.
- **연출**: 맞으면 붉게·하얗게 번쩍, KO되면 빙글빙글 날아가 별이 된다. 착탄 대기 중인 대상 발밑에는 빨간 고리가 조여 든다(필살기는 금색 마법진 + 빛기둥 + 벼락).
- 집 뒤로 들어가면 그 집이 반투명해진다.

## 10. 사운드

모두 Web Audio로 즉석 합성한다: 타건음(키마다), 잽·강타 타격음, 헛손질 버저, 방어 금속음, 반격 차임, 경고음(내게 날아오는 스킬), 벼락, KO, 승패 팡파르. 내 일이 아니면 거리에 따라 작아진다.

## 11. 온라인 구조(다음 단계 계획)

- **권위 서버**: 같은 `Sim`을 서버(Node)에서 돌린다. 시뮬레이션은 렌더링·DOM과 분리돼 있고 시드 고정 난수를 쓴다.
- **입력 = 키 토큰 스트림**: 클라이언트는 `(시퀀스 번호, 키 토큰)`과 이동 방향만 보낸다. 내 타자 진행은 클라이언트에서 즉시 예측해 보여 주고(타건감 유지), 피해·KO는 서버 결과로 확정한다.
- **관심 영역**: 오픈월드는 격자 단위로 주변 플레이어만 동기화한다. 메이플식 **채널**(채널당 수십 명)로 나눈다.
- **타속 리그**: 타속 차이가 곧 실력 차이라서 채널/매칭을 타속 구간으로 나누는 것을 검토한다(초보 채널 등).
- **매크로 대책(최대 위험)**: 자동 입력기는 이 장르의 1순위 부정행위다. 서버가 키 간격 분포(지나치게 일정한 간격, 사람 한계를 넘는 속도)를 보고 표시·격리한다. 정책·처리 기준은 운영 문서로 따로 정한다.
- 비용 주의: 서버를 띄우는 순간 호스팅 외에도 계정·남용 대응·모니터링·장애 대응 시간이 생긴다. 재미 검증(§12) 전에는 착수하지 않는다.

## 12. 이번 프로토타입이 답해야 할 질문과 성공 기준

| 질문 | 확인 방법 | 통과 기준(초안) |
|---|---|---|
| "키 한 번 = 주먹"이 손맛이 있나? | 플레이테스터 5명 이상, 타속 구간 다양하게 | 강요 없이 3판 이상 연속 플레이하는 사람이 과반 |
| 방어 단어를 압박 속에서 읽고 칠 수 있나? | 결과 화면의 방어·반격 수 / 피격 수 | 보통 실력(250~320타)의 방어 성공률 40~70% |
| 이동(방향키)과 타자 손 전환이 괴롭지 않나? | 관찰 + 인터뷰 | "이동이 불편하다"는 의견이 소수 |
| 3명 이상 난전이 읽히나? | 난전 장면 녹화 리뷰 | 누가 누구를 노리는지 말로 설명 가능 |
| 실력 차가 결과에 드러나나? | 봇 난이도별 승률 | 초보 봇 상대 승률이 고수 봇 상대보다 확연히 높음 |

통과하지 못한 항목은 수치(§13)부터 조정하고, 그래도 안 되면 해당 메커니즘을 바꾼다. 온라인(§11)은 이 표가 대체로 통과한 뒤에 시작한다.

## 14. 열린 질문

- 영문 모드: 같은 키 토큰 파이프라인에 알파벳 사전만 붙이면 되지만, 한타와 영타의 타수 기준이 달라 밸런스를 따로 잡아야 한다.
- 노트북 사용자: 방향키가 멀다. 이동을 마우스 우클릭으로도 하게 할지.
- 단어 사전의 신선도: 같은 단어가 반복되면 외워서 치게 된다. 사전 크기 vs 읽기 쉬움.
- 모바일: 물리 키보드가 전제라서 지원 대상이 아니다. 태블릿 + 블루투스 키보드는 가능성이 있다.
